# Contributing

The architecture is intentionally experimental. Changes should prefer evidence over framework growth.

Before adding a new abstraction, show which concrete controller/resource/use case requires it. Host tests are required for control-plane behavior. Hardware-specific code belongs below the portable core.

For now, external contributions are accepted under the repository's Apache-2.0 terms. A formal contributor/relicensing policy may be introduced before a stable public SDK is declared.
